# Inside Airbnb data

Place `listings.csv` or `listings.csv.gz` files here, one folder per city/snapshot, e.g.
`data/inside_airbnb/nashville/2026-09-15/listings.csv.gz`. Download them yourself from
http://insideairbnb.com/get-the-data/ . This project makes no calls to Airbnb.
